## 四、怎么复现

**前端侧**

```bash
node 测试脚本/05-红项详细用例-前端.mjs   # 直接 import validate.js 调函数
```

**后端侧**

```bash
python 测试脚本/06-红项详细用例-后端.py
```

**判定口径**

| 项 | 说明 |
|---|---|
| 是否一致 | 同一输入，前端通过 = 后端接受，才算一致 |
| 谁对 | 密码：后端规则即需求 C-29；手机号：需求只说「联系电话必填」，未定格式，属需求缺失 |
| 为什么两侧都测 | 只看界面测不出来——前端拦住时不报错，页面上看不到任何提示 |
