## 三、执行顺序（重要）

```bash
cd backend-java
rm -rf <SHOP_DATA_DIR>
SHOP_DATA_DIR=<空目录> java -jar target/shop-backend-1.0.0.jar --server.port=8000
```

**② 修复验证（39 条）**

```bash
python 01-修复验证.py
```

**③ 前端规则探测（21 条）**


```bash
python 04-生成用例总表.py
```

## 四、⚠️ 执行顺序有坑

| 坑 | 说明 |
|---|---|
| **`03-卖家密码一致性.py` 会改卖家密码** | 里面 `Abcd1234` 那次会成功改密，跑完 `seller123` 就登不上了。**必须放最后跑。** |
| **别套用第二条评审的边界套件** | `第二次评审/测试脚本/02-挑战A边界对抗测试.py` 里的 K02 用例会把密码改成 `Seller123!`，之后所有用 `seller123` 的脚本都会 401 |
| **改密后无法改回** | `seller123` 只有 2 类字符，新后端拒绝；只能清库重启 |
