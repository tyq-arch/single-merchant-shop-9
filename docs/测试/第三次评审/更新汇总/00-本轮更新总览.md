## 三、变更主题：挑战B 替换挑战A

### 3.1 购买路径变了

| 维度 | 挑战A | 挑战B |
| --- | --- | --- |
| 购买路径 | 提交购买意向 → 排队 → 卖家挑队首进入交易 | **收藏/加购 → 从购物车选件 → 下单 → 订单流转** |
| 核心对象 | 购买意向（7 态） | **订单（5 态）** |
| 库存 | 成交时扣减 | **下单占用 → 取消回补 → 完成扣减** |
| 卖家操作 | 进入交易 → 标记成功/失败/作废 | **推进订单状态 / 取消订单** |
| 新增能力 | —— | **收藏、购物车、多件下单、购物车转收藏、游客会话** |

### 3.2 订单 5 态

```
CUSTOMER_PLACED（客户下单）
  → SELLER_CONFIRMED（商家确认）
  → STOCK_READY（备货完成）
  → SHIPPING（开始发货）
  → COMPLETED（交易完成）
                          另有 CANCELLED（已取消）
```

| 谁能取消 | 可取消状态 |
| --- | --- |
| 客户 | 客户下单 / 商家确认 / 备货完成（**发货前**，FR-028） |
| 商家 | 上述三个 + 开始发货（**完成前**，FR-029） |

### 3.3 新增数据表（7 张）

`favorite`、`cart_item`、`shop_order`、`order_item`、`stock_reservation`、`guest_favorite`、`guest_cart_item`

### 3.4 接口规模

挑战A 39 个端点 → 挑战B **60 个端点**（路径 50 条）。

| 分组 | 端点数 |
| --- | ---: |
| `/api/seller/**` | 24 |
| `/api/customer/**` | 13 |
| `/api/guest/**` | 6 |
| 其他（products / categories / files / 文档） | 17 |
