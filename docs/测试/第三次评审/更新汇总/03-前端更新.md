## 七、⚠️ 需要留意的两处

### 7.1 `ProductService` 的 LIKE 转义丢了

`bc01eaf` 修改 `ProductService` 时，商品搜索改成了直接拼接通配符：

```java
where.append(" AND p.name LIKE ?");
params.add("%" + keyword.trim() + "%");     // 没有 ESCAPE，也没有用 Utils.likePattern()
```

而 `Utils.likePattern()` 方法**仍然存在**。这是上一轮已修复问题（`BUG-002`）的回归，实测 `keyword=%` 与 `keyword=_` 都会返回全部商品。

### 7.2 `FROZEN` 枚举与实际行为不一致

`enums/ProductStatus.VISIBLE` 仍包含 `FROZEN`，但第 7 项修复又让公开列表只返回 `ON_SALE`。枚举定义与实际行为出现分歧。
