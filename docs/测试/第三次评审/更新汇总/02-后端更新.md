## 三、订单状态枚举

```java
public static final class OrderStatus {
    CUSTOMER_PLACED   // 客户下单
    SELLER_CONFIRMED  // 商家确认
    STOCK_READY       // 备货完成
    SHIPPING          // 开始发货
    COMPLETED         // 交易完成
    CANCELLED         // 已取消

    CUSTOMER_CANCELLABLE = { CUSTOMER_PLACED, SELLER_CONFIRMED, STOCK_READY }
    SELLER_CANCELLABLE   = { CUSTOMER_PLACED, SELLER_CONFIRMED, STOCK_READY, SHIPPING }
}
```

> 对应需求 `FR-026`（状态推进）、`FR-028`（客户发货前可取消）、`FR-029`（商家完成前可取消）。

## 六、库存模型（NFR-005）

```
下单        → 写入 stock_reservation，占用可售量
取消        → 释放 stock_reservation，回补可售量
交易完成    → 实际扣减库存（不重复扣，因为下单时已占用）
```

> 可售量 = 库存 − 有效占用。该实现已通过测试验证（占用 2→0、回补 0→2、完成仍为 0）。
