## 一、启动环境

### 1. 启动后端（终端 A）

```bash
cd backend-java
java -jar target/shop-backend-1.0.0.jar --server.port=8000
```

> 若没有 jar：`mvn -s ../_runtime/maven-settings.xml "-Dmaven.test.skip=true" package`
> （**必须跳过测试编译**——团队自带集成测试编译不过，见报告问题 1）

### 2. 启动前端（终端 B）

```bash
cd frontend
npm install     # 首次
npm run dev
```

> ⚠️ **Node 必须 ≥ 22**（`vite@8.3.3`，Node 20 会 `EBADENGINE` 构建失败）

### 3. 确认就绪

| 检查 | 地址 | 预期 |
|---|---|---|
| 后端 | http://127.0.0.1:8000/api/products | 返回 JSON |
| 接口文档 | http://127.0.0.1:8000/docs | Swagger |
| 前端 | http://127.0.0.1:5173/ | 商品列表 |

### 4. 账号与初始数据

| 角色 | 账号 | 密码 |
|---|---|---|
| 卖家 | `seller` | `seller123` |
| 客户 | 自己注册（见 A 组） | 需满足 ≥8 位 + 3 类 |

**若环境已按本次交付预置**，应存在：

- 一级类别「手动测试大类」+ 二级类别「手动测试小类」
- 在售商品 **2 件**：`手动测试商品A`（库存 3）、`手动测试商品B`（库存 1）

> ⚠️ **不要在测试中修改卖家密码后忘记**：`seller123` 只有 2 类字符，一旦改成强密码就**改不回来**（问题 4）。
> 想恢复：停后端 → 删掉 `SHOP_DATA_DIR` 目录 → 重启 → 重新预置数据。

## 二、A 组：密码强度（6 项）⭐ 最重要

打开 **http://127.0.0.1:5173/register**

| 编号 | 怎么填 | 预期 |
|:---:|---|---|
| **M-A1** | 用户名 `manual01`、电话 `13800000001`、地点 `图书馆`、密码 **`pass1234`** | ❌ 红字「**密码强度不足：至少包含大写字母、小写字母、数字、特殊字符中的 3 类，且不少于 8 位**」 |
| **M-A2** | 密码改 **`Pass1234!`** | ✅ 注册成功 |
| **M-A3** | 新用户名，密码 **`Ab1!xyz`**（7 位 4 类） | ❌ 长度不足 |
| **M-A4** | 新用户名，密码 **`Abcd1234`**（8 位 3 类） | ✅ 注册成功 |
| **M-A5** | 新用户名，密码 **`Ab1!ab`**（6 位 4 类） | ⚠️ **已知不一致**：前端只查 ≥6 会放行，提交后后端返回 422「密码长度不能少于 8 个字符」 |
| **M-A6** | 新用户名，密码 **`abcdefgh`**（8 位仅小写） | ⚠️ **已知不一致**：前端放行，后端返回 422「密码强度不足」 |

> **M-A5 / M-A6 是本轮新发现的问题**：前端 `utils/validate.js` 的 `validateCustomerPassword` 只要求 ≥6 位，
> 但后端已升级为 ≥8 位 + 3 类。**用户在界面上不会被告知，只有提交后才看到后端报错。**
> 这两项如果复现出"前端不报错、后端报错"，就是确认了这个缺陷。

## 十、手动能发现、脚本发现不了的三件事

| 检查项 | 为什么脚本测不到 | 怎么看 |
|---|---|---|
| 页面能不能打开 | 脚本只发 HTTP，不渲染 | 19 个路由逐个点，确认不白屏 |
| 提示文案是否可读 | 脚本只断言状态码 | 看红字是不是人话、有没有暴露技术细节 |
| 跳转链路是否通 | 脚本不模拟页面跳转 | 注册→登录→浏览→下单→我的意向，整条走通 |

## 十一、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 前端打不开 | 没启动，或 8000 被旧 Python 后端占用 | 只保留 Java 后端 |
| `npm install` 报 `EBADENGINE` | Node < 22 | 升级 Node |
| 页面没有商品 | 数据库是空的 | 按 C3 发布一件 |
| 注册老是 422 | 密码不满足 ≥8 位 + 3 类 | 用 `Pass1234!` |
| 卖家登录 401 | 测试中改过密码且没改回 | 删 `SHOP_DATA_DIR` 重启并重新预置 |
| 点「我要购买」直接跳登录页 | **这是正常行为**（`C-07`） | —— |
| 想看接口返回 | F12 → Network | 或打开 `/docs` 手工发 |
