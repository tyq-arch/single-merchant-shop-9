## 二、环境要求

| 项 | 要求 |
|---|---|
| 后端 | Java 后端起在 `http://127.0.0.1:8000`（`java -jar target/shop-backend-1.0.0.jar --server.port=8000`） |
| Python | 3.10+，需 `openpyxl`（生成 Excel 用） |
| Node | ≥ 22（只有 `14-手机号前端探测.mjs` 用到） |
| PowerShell | 只有 `15-后端手机号校验.ps1` 用到 |

> **前端不需要启动**——所有用例都是打接口，不依赖页面。

## 三、推荐执行顺序

```bash
# 0) 预置环境（清库 + 建类别 + 发两件商品）
python 05-环境预置.py

# 1) 两轮自动测试（生成证据到工作区 _runtime/evidence/）
python 01-挑战A功能测试.py          # 39 条
python 02-挑战A边界对抗测试.py      # 20 条

# 2) 手动用例（25 次执行）
python 03-手动用例执行.py

# 3) 手机号用例补跑
python 04-手机号用例补跑.py
node   14-手机号前端探测.mjs

# 4) 生成交付物
python 07-生成用例总表.py           # -> 01-测试用例总表.xlsx
python 08-生成过程审计.py           # -> 04-测试过程审计.xlsx
```

其余脚本按需使用：

| 脚本 | 什么时候用 |
|---|---|
| `06-密码规则一致性验证.py` | 想确认前后端密码规则是否还一致 |
| `09-问题1修复验证.py` + `10-删除重复方法补丁.py` | 想复现"删掉重复方法后能否编译"（**09 会自动还原源码**） |
| `11-审计结果导出.py` | 想把审计结果导成文本看 |
| `12-引用检查.py` | 改完文档想查有没有断链 |
| `15-后端手机号校验.ps1` | PowerShell 环境下快速打 16 个号码 |

## 六、几个容易踩的坑

| 坑 | 说明 |
|---|---|
| **别同时起两个后端** | 旧 Python 后端和 Java 后端都抢 8000，必须只留 Java 那个 |
| **`seller123` 改了就回不来** | 它只有 2 类字符，不满足新强度策略；改坏了就删 `SHOP_DATA_DIR` 重启，再跑 `05-环境预置.py` |
| **脚本会把证据写到工作区的 `_runtime/evidence/`** | 不是本目录的 `证据/`；`证据/` 是归档快照 |
| **`03-手动用例执行.py` 依赖 `05-环境预置.py` 的产物** | 里面要找一个二级类别，环境里没有类别会失败 |
| **`14-手机号前端探测.mjs` 依赖仓库** | 它直接 import `_work/shop9/frontend/src/utils/validate.js`，没有仓库克隆跑不了 |

## 七、复现结果应当一致

清空数据库后按第三节顺序执行，应得到：

| 批次 | 预期结果 |
|---|---|
| 01 功能测试 | **39 / 39 通过** |
| 02 边界对抗 | **20 / 20 通过** |

若结果不同，先查环境（数据库残留、端口占用、Node 版本），再查脚本路径。
