## 一、升级定位

文档开篇的版本说明：

> 本版在基线（单卖家唯一在售 + 匿名口令码）基础上，经挑战 A 升级重构。
> 升级的核心思路：**「看不用登录，买必须登录」**、**多商品并发**、**库存驱动售卖**、**口令码/自动递补作废、排队/冻结保留并改造**。

一句话概括：**从「单商品 + 匿名口令码」改为「多商品 + 注册客户 + 库存驱动」。**

## 二、系统模式前后对比

| 维度 | 原基线 | 挑战 A | 变更类型 |
| --- | --- | --- | :---: |
| 商品数量 | 同一时间仅一件在售 | 可同时发布多个商品，不受数量限制 | 改 |
| 商品类别 | 无 | 2 级类别（大类 > 小类），商品**必挂二级** | 增 |
| 库存 | 无 | 库存数量（非负整数），0 自动下架，成交扣 1，可补货 | 增 |
| 商品图片 | 最多 1 张主图 | 最多 9 张，JPG/PNG，单张 ≤5MB，首图即主图，顺序固定 | 增 |
| 商品描述 | 纯文本 | 富媒体（富文本内嵌图片与视频，仅本地上传，不收外链） | 增 |
| 查找方式 | 仅浏览 | 浏览 + 搜索（关键词 / 名称 / 类别） | 增 |
| 买家身份 | 匿名，提交时填姓名电话 | **注册客户**：用户名、密码、电话、默认交易地点 | 改 |
| 下单门槛 | 无需登录 | **看不用登录，买必须登录** | 改 |
| 售卖凭据 | **口令码**（唯一认领凭证） | **口令码机制作废** | 废 |
| 撤销 / 修改意向 | 客户可改可撤 | 作废：客户无主动撤销、无修改意向信息 | 废 |
| 自动递补 | 交易失败后自动让下一位进入交易 | 作废，改为卖家标记失败时**同步选择**作废或重新排队 | 改 |
| 重新排队 | 最多 1 次 | 不限次数，排到队尾 | 改 |
| 商品状态 | 3 态：在售 / 冻结 / 已下架 | **5 态**：草稿 / 在售 / 冻结 / 售罄下架 / 手动下架 | 改 |
| 商品编辑 | 发布后不可改 | 保留（仅库存可调） | 保留 |
| 客户视角 | 无 | 新增**历史下单记录** | 增 |
| 商家视角 | 意向购买人列表 | 新增**客户台账**（固定字段）+ **购买历史** | 增 |
| 支付 / 物流 | 线下交易 | 本期不做线上支付 / 物流 | 确认 |

## 三、商品状态机变化（重点）

| | 基线 3 态 | 挑战 A 5 态 |
| --- | --- | --- |
| 状态 | `ON_SALE` 在售 · `FROZEN` 冻结 · `OFF_SHELF` 已下架 | **草稿 · 在售 · 冻结 · 售罄下架 · 手动下架** |
| 下架原因 | 仅手动下架 | 手动下架 + **售罄自动下架**（`C-28`「成交下架」移除，统一为售罄下架） |
| 恢复在售 | 重新发布 | **补货（库存调 >0）即恢复**，无需重新发布 |
| 关联作废 | 下架后关联口令码失效 | 库存 0 时**排队意向自动作废并标记「售罄」** |
