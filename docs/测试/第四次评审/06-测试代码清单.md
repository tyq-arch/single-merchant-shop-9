# 挑战C 测试代码清单

> 可执行脚本：`测试脚本/01-全链路功能测试.py`
> 本文件按用例列出**实际执行的代码**，与 `02-挑战C测试用例.xlsx` 的「测试代码」列一致。

## 使用方式

```bash
# 1. 起后端（干净数据目录）
cd backend-java
mvn -s <settings.xml> -Dmaven.test.skip=true package
SHOP_DATA_DIR=./data-c java -jar target/shop-backend-1.0.0.jar --server.port=8000

# 2. 跑测试
python 测试脚本/01-全链路功能测试.py
```

> 脚本里维护了公共的 `api()` 封装、`new_order()` / `pay()` / `to_cart()` 辅助函数，
> 每条用例的代码都调用这些封装。
