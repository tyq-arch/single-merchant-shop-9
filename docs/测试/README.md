## 二、测试结论摘要

- 黑盒功能测试：**113 条用例，通过 111 条，失败 2 条，通过率 98.2%**
- 开发自测回归（仓库自带 pytest）：**28 条全部通过**
- 确认缺陷：**2 个**（中级 1 个、低级 1 个，无阻塞级缺陷）
- 观察项与改进建议：**10 项**
- 功能验收校验：**47 项，通过 45 项**
- 上线合规检查：**35 项，通过 22 项、有条件通过 4 项、不通过 9 项**

**核心结论**：三类状态机（商品 3 态、意向 7 态、口令码 2 态）的合法迁移全部可达、非法迁移均被正确拒绝；
先到先得排队在 20 线程并发下仍保持序号唯一连续；口令码在四种情形下均正确失效。
核心交易主流程未发现功能缺陷；当前版本尚不满足上线条件，需完成 2 个缺陷修复及若干整改。

## 三、已确认缺陷

| 编号 | 标题 | 严重级别 | 关联需求 |
| --- | --- | --- | --- |
| BUG-001 | 发布商品时价格不足 1 分，接口返回 HTTP 500 | 中（Major） | FR-001、NFR-009 |
| BUG-002 | 历史商品搜索未转义 LIKE 通配符，搜索结果不准确 | 低（Minor） | FR-004 |

## 五、如何复现

```bash
# 1) 启动后端
cd backend && pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

# 2) 启动前端
cd frontend && npm install && npm run dev

# 3) 执行开发自测（28 条）
cd backend && pytest -v

# 4) 执行黑盒功能测试（113 条，需后端已启动）
python docs/测试/证据/functional_suite.py
# 结果打印到控制台，并写入 docs/测试/证据/test_results.json
```
