## 二、测试代码清单与测试内容

### 1. `functional_suite.py` —— 黑盒功能测试套件（113 条）

对**运行中的服务**发起真实 HTTP 请求，逐条记录「预期 vs 实际」。
共划分 11 个测试模块，每个模块在源码中以注释块标注了**需求追溯**与**测试内容**：

| 模块 | 测试模块名称 | 需求追溯 | 用例数 | 测试内容概要 |
| :---: | --- | --- | ---: | --- |
| A | 公开商品浏览 | FR-043 ~ FR-046 | 6 | 买家端商品页三态（无商品/在售/交易中）、商品详情、下架不可见、路由优先级 |
| B | 卖家登录与鉴权 | FR-032 ~ FR-035 | 10 | 登录成功/失败、无注册、令牌校验、改密与密码长度 |
| C | 商品发布与管理 | FR-001 ~ FR-012 | 21 | 发布校验、唯一在售、冻结/解冻、下架、口令码失效、不可编辑 |
| D | 排队与口令码 | FR-013 ~ FR-026 | 15 | 提交意向、口令码生成与格式、先到先得、查询/修改/撤销、补位 |
| E | 交易流程与状态机 | FR-027 ~ FR-031 | 18 | 进入交易、标记成败、自动递补、队空回售、作废与重新排队 |
| F | 历史记录、意向列表与操作日志 | FR-004 ~ FR-007 / FR-042 | 15 | 历史列表与详情、多轮交易保留、脱敏、状态筛选、分页、操作日志 |
| G | 意向购买人 CSV 导出 | FR-018 | 3 | 导出格式、BOM、表头数据、鉴权 |
| H | 商品主图上传 | FR-001 / NFR-012 | 8 | 格式与大小限制、静态访问、非法文件处理 |
| I | 并发一致性 | NFR-013 / NFR-014 | 4 | 并发不丢失、序号唯一连续、防超卖、先到先得不可干预 |
| J | 前端页面与前后端联调 | FR-051 / FR-052 | 5 | 12 条路由可访问、模块编译、代理连通 |
| K | 安全与健壮性 | NFR-005 / NFR-006 / NFR-009 | 8 | SQL 注入、路径穿越、越权访问、XSS 存储、异常输入返回 4xx |
| | **合计** | | **113** | |

**运行方式**

```bash
# 1) 先启动后端（127.0.0.1:8000）与前端开发服务器（127.0.0.1:5173）
# 2) 执行套件
python functional_suite.py
# 结果打印到控制台，并写入 运行输出/test_results.json
```

> 建议运行前重置后端数据库，以获得确定性结果。

### 2. `probe.py` —— 缺陷定向验证脚本（6 个验证点）

针对**代码走查中怀疑的边界问题**逐一验证，用于给缺陷报告提供实测证据。
每个验证点在源码中以注释与打印标题标注，共 6 个：

| 序号 | 验证内容 | 结论 |
| :---: | --- | --- |
| 1 | 价格不足最小货币单位（0.001 元） | 触发 HTTP 500（缺陷 BUG-001 证据） |
| 2 | 价格恰好等于文档规定上限 9999999 | 正常发布 |
| 3 | 价格略超上限 9999999.01 | 返回 422，符合预期 |
| 4 | 历史搜索关键词包含 SQL LIKE 通配符 `_` | 返回全部商品（缺陷 BUG-002 证据） |
| 5 | 分页接口 page / page_size 边界取值 | 越界返回 422 |
| 6 | 未处理异常的表现（500 是否泄漏堆栈） | 返回纯文本 500，非统一错误结构 |

**运行方式**

```bash
python probe.py     # 需后端已启动
```

### 3. `开发自测用例/` —— 开发自测 pytest 用例（28 条）

来自仓库 `backend/tests/`，由后端开发岗编写，覆盖接口逻辑与数据库状态，作为测试的第 1 层。
本目录保留一份副本便于离线查阅；**以其仓库路径 `backend/tests/` 为准**。

| 文件 | 测试内容 |
| --- | --- |
| `conftest.py` | 公共夹具：每个用例使用独立临时数据库，提供登录令牌与已发布商品 |
| `test_seller_auth.py` | 卖家登录成功/失败、无注册接口、令牌校验、修改密码 |
| `test_catalog.py` | 商品浏览、发布、唯一在售、冻结/解冻、下架与口令码失效 |
| `test_buyer_flow.py` | 买家意向提交、口令码查询/修改/撤销、FIFO 排队 |
| `test_transaction.py` | 进入交易、标记成败、自动递补、作废与重新排队 |
| `test_history.py` | 历史记录、意向购买人列表与 CSV 导出、操作日志 |

**运行方式**

```bash
cd backend && pytest -v
```
