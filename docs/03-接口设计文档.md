## 1. 通用约定

| 项目 | 约定 |
|---|---|
| Base URL | `http://127.0.0.1:8000` |
| 编码 | 请求/响应体统一 UTF-8，`Content-Type: application/json` |
| 时间格式 | `YYYY-MM-DD HH:MM:SS`（本地时间字符串） |
| 金额 | 出参为元（保留 2 位小数，数值类型）；入参 `price` 为元 |
| 鉴权 | 卖家接口需 `Authorization: Bearer <token>`；买家与公开接口免鉴权 |
| 分页 | 查询参数 `page`（≥1）、`page_size`（1~100，默认 10） |
| 错误格式 | 统一 `{"error": {"code": "...", "message": "..."}}` |

### 错误码

| HTTP | code | 含义 |
|---|---|---|
| 400 | `BUSINESS_ERROR` | 通用业务错误 |
| 401 | `UNAUTHORIZED` | 未登录 / 凭证无效 / 旧密码错误 |
| 404 | `NOT_FOUND` | 资源不存在 |
| 409 | `CONFLICT` | 状态冲突（重复发布、冻结中提交、状态不允许等） |
| 410 | `COMMAND_CODE_INVALID` | 口令码无效或已失效 |
| 422 | `VALIDATION_ERROR` | 请求参数校验失败 |

### 状态取值

| 类别 | 取值 |
|---|---|
| 商品状态 | `ON_SALE`（在售）、`FROZEN`（已冻结）、`OFF_SHELF`（已下架） |
| 意向状态 | `QUEUED`、`CANCELLED`、`IN_TRANSACTION`、`SUCCESS`、`FAILED`、`VOIDED`、`REQUEUED` |
| 买家端商品可见态 | `NONE`（无商品在售）、`ON_SALE`、`FROZEN`（商品交易中） |

## 3. 公开接口

### 3.1 GET /api/products/current —— 当前商品

无商品在售时 `state=NONE`；冻结时 `state=FROZEN` 且提示"商品交易中"。

**响应（在售）**

```json
{
  "state": "ON_SALE",
  "message": null,
  "product": {
    "id": "8f1c...", "name": "手工陶瓷杯", "description": "手作限量",
    "image_url": "/uploads/ab12.jpg", "price": 99.9,
    "status": "ON_SALE", "status_label": "在售",
    "published_at": "2026-10-05 10:00:00", "updated_at": "2026-10-05 10:00:00"
  }
}
```

**响应（无货）**

```json
{ "state": "NONE", "product": null, "message": "暂无商品在售" }
```

**响应（冻结）**

```json
{ "state": "FROZEN", "product": { "...": "..." }, "message": "商品交易中" }
```

### 3.2 GET /api/products/{product_id} —— 商品详情

- 200：`{"product": {...}}`
- 404：商品不存在或已下架 → `NOT_FOUND`

## 4. 买家接口

### 4.1 POST /api/buyer/intents —— 提交购买意向

**请求**

```json
{ "product_id": "8f1c...", "buyer_name": "张三", "buyer_phone": "13800001234" }
```

**响应 200**

```json
{
  "order": {
    "order_id": "b7d2...", "product_id": "8f1c...",
    "buyer_name": "张三", "buyer_phone": "13800001234",
    "status": "QUEUED", "status_label": "排队中",
    "queue_position": 1, "requeue_count": 0,
    "command_code": "K7M2PQ9XTR",
    "created_at": "2026-10-05 10:05:00",
    "product_snapshot": { "name": "手工陶瓷杯", "price": 99.9, "description": "手作限量", "image_url": "/uploads/ab12.jpg" }
  },
  "command_code": "K7M2PQ9XTR",
  "queue_position": 1,
  "notice": "请务必自行保存口令码，这是查询、修改、撤销该意向的唯一凭证，丢失无法找回。"
}
```

**错误**：409 商品交易中 / 已下架；404 商品不存在；422 参数不合法。

### 4.2 GET /api/buyer/intents/{code} —— 凭口令码查询

**响应 200**

```json
{
  "order": { "order_id": "b7d2...", "status": "QUEUED", "status_label": "排队中", "queue_position": 2, "...": "..." },
  "position": 2,
  "can_edit": true,
  "can_cancel": true,
  "product_status": "ON_SALE"
}
```

- 进入交易后：`status=IN_TRANSACTION`、`position=1`、`can_edit=false`、`can_cancel=false`
- 410：口令码不存在 / 已失效 / 已过期 / 对应意向已终结

### 4.3 PATCH /api/buyer/intents —— 修改信息（仅排队中）

**请求**（字段至少提供一个）

```json
{ "code": "K7M2PQ9XTR", "buyer_phone": "13900002222" }
```

**响应 200**：修改后的 `order` 对象，`queue_position` 不变。
**错误**：409 当前状态不可修改（已进入交易/已终结）；410 口令码无效。

### 4.4 POST /api/buyer/intents/cancel —— 撤销意向（仅排队中）

**请求**

```json
{ "code": "K7M2PQ9XTR" }
```

**响应 200**

```json
{ "order_id": "b7d2...", "status": "CANCELLED", "message": "意向已撤销，队列已自动补位" }
```

**错误**：409 已进入交易不可撤销；410 口令码无效。

## 5. 卖家接口

### 5.1 POST /api/seller/login —— 登录

**请求**：`{ "username": "seller", "password": "seller123" }`

**响应 200**

```json
{
  "token": "c2VsbGVy...", "token_type": "Bearer", "expires_at": 1791200000,
  "seller": { "id": "...", "username": "seller" }
}
```

**错误**：401 用户名或密码错误。后台**无退出登录**接口。

### 5.2 POST /api/seller/password —— 修改密码

鉴权：Bearer。**请求**：`{ "old_password": "seller123", "new_password": "newpass123" }`
**响应 200**：`{ "message": "密码修改成功" }`；**错误**：401 旧密码不正确。

### 5.3 GET /api/seller/product/current —— 当前商品

**响应**：`{ "product": {...} }` 或 `{ "product": null, "message": "当前无在售/交易中的商品" }`

### 5.4 POST /api/seller/products —— 发布商品

**请求**

```json
{ "name": "手工陶瓷杯", "price": 99.9, "description": "手作限量", "image_url": "/uploads/ab12.jpg" }
```

- `name`、`price` 必填；`description`、`image_url` 选填（图片最多一张）
- **响应 200**：`{ "product": {...}, "message": "商品发布成功" }`
- **错误**：409 已有在售/交易中商品；422 参数不合法

### 5.5 POST /api/seller/products/{id}/off-shelf —— 下架

- **响应 200**：`{ "product": {...OFF_SHELF...}, "message": "商品已下架，关联口令码全部失效" }`
- 副作用：作废所有未终结意向、清空队列、**关联口令码全部失效**（FR-003/FR-026）
- **错误**：409 商品已下架

### 5.6 POST /api/seller/products/{id}/freeze —— 手动冻结

- **响应 200**：商品变 `FROZEN`，队列封口，不再收新意向
- **错误**：409 已冻结 / 已下架

### 5.7 POST /api/seller/products/{id}/unfreeze —— 手动解冻

- 恢复 `ON_SALE`，重新收意向；**不直接进入交易**（FR-010）
- **错误**：409 存在进行中的交易 / 商品非冻结态

### 5.8 POST /api/seller/products/{id}/start-transaction —— 与队首进入交易

按先到先得取**队列第 1 位**，订单置 `IN_TRANSACTION`，商品自动冻结（FR-011）。

**响应 200**

```json
{
  "order": { "order_id": "b7d2...", "status": "IN_TRANSACTION", "status_label": "已进入交易", "...": "..." },
  "product": { "status": "FROZEN", "status_label": "已冻结", "...": "..." },
  "message": "已与队列第一位进入交易，商品自动冻结，队列已封口"
}
```

**错误**：409 队列为空 / 已有进行中的交易 / 商品已下架。

> 需求 TBD-02 决策：进入交易**只能针对队首**，由卖家主动触发，无超时自动进入。

### 5.9 GET /api/seller/products/{id}/intents —— 意向购买人列表

查询参数：`page`、`page_size`、`status`（可选）。

**响应 200**

```json
{
  "items": [
    { "order_id": "b7d2...", "buyer_name": "张三", "buyer_phone": "13800001234",
      "submitted_at": "2026-10-05 10:05:00", "queue_position": 1,
      "status": "QUEUED", "status_label": "排队中" }
  ],
  "total": 1, "page": 1, "page_size": 10
}
```

> 脱敏规则：订单终结或商品已下架后，`buyer_phone` 返回 `前3位****后4位`；交易进行中返回完整号码（FR-019/NFR-003）。

### 5.10 GET /api/seller/products/{id}/intents/export —— 导出 CSV

- 返回 `text/csv; charset=utf-8`（含 BOM，Excel 可直接打开）
- 列：`姓名, 联系电话, 提交时间, 排队序号, 状态`

### 5.11 GET /api/seller/history —— 历史商品列表

查询参数：`page`、`page_size`、`keyword`（可选，按名称模糊）。

**响应 200**

```json
{
  "items": [
    { "id": "8f1c...", "name": "手工陶瓷杯", "price": 99.9,
      "status": "OFF_SHELF", "status_label": "已下架",
      "published_at": "2026-10-05 10:00:00",
      "transaction_summary": { "failed_rounds": 1, "buyer_count": 2,
        "final_result": "SUCCESS", "final_result_label": "交易成功",
        "last_transaction_at": "2026-10-05 11:00:00" } }
  ],
  "total": 1, "page": 1, "page_size": 10
}
```

### 5.12 GET /api/seller/history/{id} —— 历史商品详情

**响应 200**：商品快照 + 完整交易链路（多次失败全部保留）+ 每个买家对应结果。

```json
{
  "id": "8f1c...", "name": "手工陶瓷杯", "status": "OFF_SHELF",
  "transaction_summary": { "failed_rounds": 1, "final_result": "SUCCESS", "...": "..." },
  "buyers": [
    { "order_id": "b7d2...", "buyer_name": "A", "buyer_phone": "138****0001",
      "status": "VOIDED", "status_label": "已作废", "...": "..." },
    { "order_id": "c9e3...", "buyer_name": "B", "buyer_phone": "138****0002",
      "status": "SUCCESS", "status_label": "交易成功", "...": "..." }
  ],
  "transactions": [
    { "result": "FAILED", "result_label": "交易失败", "created_at": "..." },
    { "result": "SUCCESS", "result_label": "交易成功", "created_at": "..." }
  ]
}
```

- **错误**：409 该商品尚未下架，暂不进入历史记录

### 5.13 POST /api/seller/orders/{order_id}/transaction —— 标记交易结果

**请求**：`{ "result": "SUCCESS" }` 或 `{ "result": "FAILED", "note": "买家未到场" }`

- **成功（SUCCESS）**：订单 → `SUCCESS`；商品 → `OFF_SHELF`；该订单与商品全部口令码失效；其余未终结意向作废；进入历史记录（FR-028）
- **失败（FAILED）**：订单 → `FAILED`、口令码失效；**队列有人则自动让下一位递补进入交易并再次冻结；队列为空则商品恢复在售**（FR-029/FR-021）
- **响应 200**：`{ "order": {...}, "product": {...}, "message": "..." }`
- **错误**：409 非进行中交易

### 5.14 POST /api/seller/orders/{order_id}/void —— 作废失败者

- 仅 `FAILED` 可作废 → `VOIDED`；只影响该买家本人（FR-030）
- **错误**：409 状态不允许

### 5.15 POST /api/seller/orders/{order_id}/requeue —— 失败者重新排队

- 仅 `FAILED` 可重新排队；放回**队尾**、更新提交时间、最多 **1 次**（需求状态机）
- **重新生成口令码**（TBD-03 决策）
- **响应 200**：`{ "order": {...REQUEUED...}, "command_code": "新口令码", "queue_position": 2, "message": "..." }`
- **错误**：409 已重排过一次 / 商品已下架 / 状态不允许

### 5.16 GET /api/seller/logs —— 操作日志

**响应 200**：`{ "items": [{ "action": "PUBLISH_PRODUCT", "detail": "发布商品：手工陶瓷杯", "created_at": "..." }], "total": 12, "page": 1, "page_size": 10 }`

## 6. 文件接口

### 6.1 POST /api/files/images —— 上传商品主图

- `multipart/form-data`，字段名 `file`
- 限制：扩展名 jpg/jpeg/png/gif/webp；大小 ≤ 5MB（`SHOP_MAX_IMAGE_BYTES`）
- **响应 200**：`{ "url": "/uploads/e5a1....jpg", "original_name": "cup.jpg", "size": 204800 }`
- 返回的 `url` 可直接作为发布商品的 `image_url`（通过 `GET /uploads/...` 静态访问）
- **错误**：400 格式不支持 / 超出大小 / 空文件

## 7. 端到端业务时序

### 7.1 正常成交

```
卖家登录 → 发布商品(ON_SALE)
买家A提交意向 → 排队1，得到口令码A
买家B提交意向 → 排队2，得到口令码B
卖家 start-transaction → A进入交易，商品FROZEN，队列封口
卖家 mark(SUCCESS) → A成功；商品OFF_SHELF；A、B口令码均失效
卖家 GET /history/{id} → 可见快照与 A 的交易成功记录
```

### 7.2 失败后自动递补

```
... 队列 A(1), B(2) ...
卖家 start-transaction → A进入交易，商品FROZEN
卖家 mark(FAILED) → A=FAILED且口令码失效；B自动递补进入交易；商品继续FROZEN
卖家 void(A) → A=VOIDED（或 requeue(A) → A放回队尾并生成新口令码）
卖家 mark(SUCCESS) → B成功；商品OFF_SHELF；所有口令码失效
```

### 7.3 队列为空时失败

```
队列仅 A；start-transaction → A进入交易
mark(FAILED) → A=FAILED；队列为空 → 商品恢复ON_SALE，继续接收新意向
卖家 requeue(A) → A回到队尾第 1 位，生成新口令码
```
