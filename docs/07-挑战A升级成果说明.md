**项目：** 在线购物系统（单商家 · 挑战A升级版）
**角色：** 成员2 —— 后端开发岗
**日期：** 2026-10-22
**版本：** V1.0

---

## 1. 本次更新概述

依据仓库中的《需求规格说明书-挑战A升级版》，后端由“单商品在售 + 匿名口令码意向”整体升级为“多商品 + 客户账号 + 库存驱动 + 每商品独立队列”的形态：

- 多商品同时在售，新增二级类别、库存、多图、富媒体描述
- 新增客户注册 / 登录 / 登出 / 改密 / 历史下单
- 删除口令码、匿名意向、买家撤销与修改
- 交易失败改为“标记失败 + 同步选择失败者处理（VOID / REQUEUE）”，取消自动递补
- 新增商家客户台账、历史商品交易链路、操作日志
- 后端实现语言由 Python 迁移为 Java（Spring Boot 2.7.18），接口结构保持 REST + JSON 风格

> 说明：本次仅升级 Java 版后端，仓库中原有 `backend/`（Python 版）保持原样，便于对照。

## 3. 功能升级对照

| 需求范围 | 实现情况 |
|---|---|
| FR-001/002 多商品同时在售、发布商品 | 支持任意数量商品同时在售；发布即生效 |
| FR-003/004 二级类别与类别树 | 大类 > 小类两级；商品必须挂小类；仅支持新增/重命名/删除，有子类或商品禁止删除 |
| FR-005/006/039 库存 | 库存为非负整数；支持补货与调减；0 自动下架，>0 自动恢复在售 |
| FR-008/009 多图与富媒体 | 最多 9 张 JPG/PNG（单张 ≤5MB）；描述支持本地上传图片/视频，不接受外链 |
| FR-010/019 搜索与游客浏览 | 支持关键词、类别（一级自动含子类）检索；游客可浏览不可下单 |
| FR-017/018 客户账号 | 注册、登录、登出、改密；口令码机制整体移除 |
| FR-020~025 购买意向 | 必须登录；每商品独立队列、先到先得、人数不限；同一客户同商品仅一个有效意向；无撤销/修改入口 |
| FR-026/027 交易冻结 | 与队首进入交易时商品自动冻结；单商品同时仅一笔进行中交易 |
| FR-028/029/030 交易结果 | 成功扣 1 库存；失败库存不变并立即恢复在售；失败者同一动作内 VOID 或 REQUEUE（队尾、不限次数） |
| FR-031/032/033 历史与台账 | 客户历史下单；商家客户台账固定字段；商家可查看客户购买历史与商品交易链路 |
| FR-034 售罄作废 | 库存归零时排队意向自动置 `SOLD_OUT` 并清空队列 |
| FR-035/036/037 卖家账号 | 固定账号登录；无注册无退出；改密校验旧密码且新密码 ≥8 位 |
| FR-040 操作日志 | 登录、改密、类别、发布、库存、上下架、冻结、交易等关键操作留痕 |

## 4. 接口变更摘要

**新增**

- 客户：`/api/customer/register|login|logout|me|password|intents|orders`
- 卖家：`/api/seller/categories`（增删改查）、`/api/seller/products/{id}/stock|on-shelf`、`/api/seller/intents/{id}/transaction`、`/api/seller/customers`、`/api/seller/history`
- 文件：`/api/files/media`（富媒体素材）

**删除**

- `/api/products/current`（单商品在售模型）
- `/api/buyer/*`（匿名意向、口令码查询/修改/撤销）
- `/api/seller/product/current`、`/api/seller/orders/{id}/void`、`/api/seller/orders/{id}/requeue`
- 错误码 `410 COMMAND_CODE_INVALID`；状态 `CANCELLED`、买家可见态 `NONE`

**状态与错误码**

- 商品 4 态：`ON_SALE` / `FROZEN` / `SOLD_OUT` / `OFF_SHELF`
- 意向 7 态：`QUEUED` / `REQUEUED` / `IN_TRANSACTION` / `SUCCESS` / `FAILED` / `VOIDED` / `SOLD_OUT`
- 统一错误结构 `{"error":{code,message}}`，校验错误附 `details`

cd backend-java
mvn spring-boot:run
