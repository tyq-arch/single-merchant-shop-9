# 单商家在线购物系统（挑战A升级版）

单卖家、多商品同时在售的在线购物系统。买家注册登录后对商品提交购买意向，按商品独立排队、先到先得；卖家在后台管理商品、库存、类别并完成线下交易确认。

- 后端：Java 8 + Spring Boot 2.7.18 + SQLite
- 前端：Vue 3 + Vite + Element Plus
- 接口风格：REST / JSON，OpenAPI 3 文档

## 功能概览

| 模块 | 能力 |
|---|---|
| 商品浏览 | 多商品列表、商品详情、关键词搜索、二级类别筛选 |
| 客户账号 | 注册、登录、登出、修改密码、个人资料 |
| 购买意向 | 登录后提交意向；每个商品独立队列、先到先得；同一客户同一商品仅一个有效意向 |
| 库存 | 库存非负整数；成交扣 1；库存归零自动售罄下架，排队意向同步售罄作废；补货后恢复在售 |
| 交易 | 卖家与队首进入交易（商品自动冻结）；成交或失败；失败时选择作废或重新排队到队尾 |
| 商家后台 | 商品发布（不可编辑）、多图与富媒体描述、类别维护、库存调整、上下架、冻结/解冻 |
| 历史与台账 | 客户历史下单、商家历史商品交易链路、客户台账与 CSV 导出 |
| 操作日志 | 登录、改密、商品、类别、库存、交易等关键操作留痕 |

商品不提供编辑功能；商品必须挂在二级类别下；库存为 0 的商品不会出现在公开列表。

## 后端快速开始

环境要求：JDK 8、Maven 3.9+。

```bash
cd backend-java
mvn spring-boot:run
```

或打包后运行：

```bash
cd backend-java
mvn -q package
java -jar target/shop-backend-1.0.0.jar
```

- 服务地址：`http://127.0.0.1:8000`
- 在线接口文档：`http://127.0.0.1:8000/docs`
- 默认卖家账号：`seller` / `seller123`（首次启动自动建库并写入）
- 数据库：`backend-java/data/shop-v2.db`（首次启动自动创建）
- 上传文件：`backend-java/uploads/`

修改数据库或上传目录可通过环境变量 `SHOP_DB_PATH`、`SHOP_UPLOAD_DIR` 覆盖。

### 运行测试

```bash
cd backend-java
mvn test
```

集成测试覆盖多商品、二级类别、客户账号、独立队列、库存上下架、交易成功/失败、售罄作废、客户历史与商家台账等主流程。

### 校验规则说明

- 联系电话：后端接受手机号、座机、`+86` 前缀及空格/短横线/括号写法，保存前统一归一化为纯数字；前端注册页限制 11 位手机号。
- 卖家密码：修改密码时新密码须为 8~128 位；旧密码错误返回 401。
- 客户密码：注册与改密须为 6~128 位。

## 前端快速开始

环境要求：Node.js 18+。

```bash
cd frontend
npm install
npm run dev
```

- 开发地址：`http://127.0.0.1:5173`
- 开发期由 Vite 将 `/api`、`/uploads` 代理到 `http://127.0.0.1:8000`
- 生产构建：`npm run build`，产物在 `frontend/dist/`

后端接口分为四组：

- `/api`：公开的商品列表、详情与类别树
- `/api/customer`：客户注册、登录、意向与历史订单
- `/api/seller`：卖家登录、类别、商品、库存、交易、台账、日志
- `/api/files`：商品图片与富媒体素材上传

## 并发说明

后端以单进程方式运行：SQLite 开启 WAL，写操作使用 `BEGIN IMMEDIATE`，并在 JVM 内加公平写锁，保证排队与交易操作的顺序性。部署时请保持单实例单 worker，不要以多实例共享同一数据库文件。
