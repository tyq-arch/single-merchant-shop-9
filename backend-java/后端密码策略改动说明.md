# 后端代码改动说明：密码策略对齐需求规格说明书

> 依据《需求规格说明书-挑战A升级版.md》中 C-29、NFR-003、FR-017、FR-037、AC-006 条款，对后端 Java 实现进行修正。

## 一、需求依据

需求规定：**客户与卖家统一**采用以下密码规则

- 密码长度 ≥ 8 位；
- 强度要求：大写字母、小写字母、数字、特殊字符 **至少 3 类**。

对应条款：

| 编号 | 内容 |
|---|---|
| C-29 | 密码规则：买家与卖家统一——≥8位 + 强度要求（大写+小写+数字+特殊字符至少3类） |
| NFR-003 | 账号安全：客户/卖家密码哈希存储，支持修改密码；密码规则同上 |
| FR-017 | 客户注册：用户名、密码（≥8位+强度要求）、电话、默认交易地点 |
| FR-037 | 卖家修改密码：校验旧密码，新密码≥8位+强度要求 |
| AC-006 | 客户注册：用户名/密码（≥8位+强度要求）/电话/默认交易地点注册成功 |

## 二、改动前的问题

原实现未完整落实强度要求：

| 入口 | 原校验 | 缺口 |
|---|---|---|
| 客户注册 | 仅 ≥6 位 | 无 8 位下限、无强度校验 |
| 客户修改密码 | 仅 ≥6 位 | 无 8 位下限、无强度校验 |
| 卖家修改密码 | 仅 ≥8 位 | 无强度校验 |

## 三、改动内容

### 1. 新增统一强度校验方法

文件：`src/main/java/com/shop/web/Validation.java`

新增静态方法 `password()`，统一实施「≥8 位 + 至少 3 类字符」规则，供客户与卖家共用。

```java
/** 密码校验：≥8 位且满足强度（大写/小写/数字/特殊字符至少 3 类）（C-29 / NFR-003）。 */
public static String password(String value, String location, String field, String label) {
    String pwd = text(value, location, field, 8, 128, label);
    int classes = 0;
    if (pwd.matches(".*[A-Z].*")) {
        classes++;
    }
    if (pwd.matches(".*[a-z].*")) {
        classes++;
    }
    if (pwd.matches(".*[0-9].*")) {
        classes++;
    }
    if (pwd.matches(".*[^A-Za-z0-9].*")) {
        classes++;
    }
    if (classes < 3) {
        throw error(location, field,
                label + "强度不足：至少包含大写字母、小写字母、数字、特殊字符中的 3 类，且不少于 8 位");
    }
    return pwd;
}
```

## 四、影响分析

| 关注点 | 说明 |
|---|---|
| 现有账号登录 | 登录不做强度校验，存量账号不受影响，可正常登录 |
| 卖家初始账号 | 种子密码 `seller123` 仅用于登录，不受影响 |
| 新增注册/改密 | 均需满足 ≥8 位 + 至少 3 类字符 |
| 测试覆盖 | 已同步更新示例密码，编译验证通过 |
